# Nueva Galeria Dinamica

Proyecto PHP basado en la practica `05-galeria_dinamica`, pero con una estructura mas limpia y una interfaz renovada a partir de disenos de Stitch.

## Documentacion

- `docs/README.md`
- `docs/prds/01-nueva_galeria_dinamica.md`

## Dependencias

- PHP con PDO MySQL
- Base `nueva_galeria_dinamica`
- Tabla `fotos`

## Entradas principales

- `index.php`: listado principal
- `detalle.php?id=...`: detalle y edicion
- `subir.php`: carga de nuevas imagenes

## Nota de datos

Este proyecto tiene una base propia. Si necesitas preparar la estructura, ejecuta el script incluido en esta carpeta:

- `nueva_galeria_dinamica.sql`
